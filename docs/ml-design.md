# ML設計

初期モデルはscikit-learnの正則化ロジスティック回帰を基準モデルとする。確率の解釈、再現性、Lambdaパッケージの小ささ、説明容易性を優先する。十分なサンプルと非線形性の有効性が確認された後にLightGBMを比較対象として評価し、確率校正後にのみ採用する。

入力は契約で固定した市場特徴量とする。ラベルは「エントリー後の所定期間内に、コスト込みでTP/SLのどちらへ先に到達したか」等をバージョン管理する。同一時点から得た重複サンプルによる漏洩、未来データ、全期間に適合させたスケーラー、銘柄横断の時刻重複に注意する。

評価は時系列順のインサンプル・アウトオブサンプル、間隔・除外期間を考慮したTimeSeriesSplit、移動・起点固定型ウォークフォワードで行う。閾値はアウトオブサンプルで固定し、初期例は `win_probability >= 0.60` かつ `expected_return > 0` とする。正解率だけでなくBrierスコア、確率校正、適合率、判定対象率、取引後指標を評価する。

モデル成果物、特徴量スキーマ、学習期間、コミットハッシュ、評価指標をS3に保存し、`model_version` とチェックサムを持たせる。スキーマ・バージョン不一致、NaN、範囲外、推論例外はVETOとする。Lambdaのコールドスタートと費用を抑えるため、小型モデルをパッケージまたはS3から初期化時に一度ロードする。

## Phase 7実装

基準モデルは勝率用の正則化ロジスティック回帰、期待return用のRidge回帰とした。学習期間だけで標準化をfitし、その後の独立期間でロジットをPlatt校正し、最後の20%をOOSとして一度だけ評価する。分割境界にはgapを置き、学習・校正以前の期間では5分割TimeSeriesSplitも実施する。

固定特徴量はdirection、RSI、ATR/価格、EMA乖離、方向付きEMA乖離、直近return、volatility、spread points、hourのsin/cos、曜日のsin/cos、RR、SL距離率、TP距離率の15個である。1モデルは1symbol・1timeframeに限定する。モデル入力にlabelや将来価格を含めない。

TP/SL先着ラベルは取引コストをreturnから控除する。同一OHLCバー内のTP/SL両到達は順序を推測せず `AMBIGUOUS`、評価期間内に未到達なら `CENSORED` とし、採用方針を確定するまで学習から除外する。

pickle、joblib、scikit-learnオブジェクトはLambdaで復元しない。標準化値、線形係数、校正係数を64 KiB以下の厳格JSONへ書き出し、S3キーとSHA-256をdeploy設定で固定する。特徴量順序、対象scope、モデル版、有限数、配列長、checksumのいずれかが不正なら `ML_INFERENCE_ERROR` としてVETOする。

初期閾値は勝率0.60以上、期待return 0.0以上だが、これは収益性を保証する値ではない。実データのOOSでBrier score、ROC AUC、閾値precision、選択率、return MAE、取引後DDを確認してから固定する。閾値をOOS結果へ繰り返し最適化しない。
