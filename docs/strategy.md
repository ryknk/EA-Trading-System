# 戦略

初期戦略は説明可能な複数時間足のトレンドフォローとする。D1で終値とEMA200、H4でEMA50/EMA200、H1で押し目またはブレイクアウトを確定足だけで判定する。Phase 2ではRSI/ATRを戦略固有の適格条件として扱い、口座・執行条件に関係するスプレッド、取引時間、異常ボラティリティは後続Phaseで独立したフィルターにする。

Phase 2の厳密な判定は次の通り。BUYはD1終値がD1の低速EMAより上、かつH4の高速EMAが低速EMAより上。SELLはすべて逆とする。H1ブレイクアウトはシグナルバーの終値が、その前の設定本数の最高値・最安値をバッファー込みで抜けた場合とする。押し目はシグナルバーがH1の高速EMAへATR比率以内に接触し、EMAのトレンド方向側で反転して確定した場合とする。RSI範囲とATR下限を通過した候補だけを返す。ブレイクアウトと押し目が同時成立した場合はブレイクアウトを理由として採用する。

戦略は方向、参照足時刻、特徴量、SL/TP候補、理由コードを返すだけで、ロット計算、外部API、発注を行わない。指標期間・閾値・時間足は設定値とし、BUY/SELLを対称に実装する。初期リリースでは同一シンボルへの追加エントリーを禁止する。

固定値探索を最小化し、頑健なパラメータ領域、取引コストを悪化させたストレステスト、期間・市場局面別の成績を評価する。未来足参照と未確定足の再描画を禁止する。

EA起動時は直前の古いバーを評価せず、エントリー時間足の次のバーが開始した時だけ、新たに確定したshift 1を評価する。指標またはバーデータ不足はシグナルエラーであり、候補を生成しない。Phase 2は候補ログまでで、発注機能を持たない。
