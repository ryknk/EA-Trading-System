# 実装ロードマップ

各Phaseは実装前に目的、変更ファイル、設計判断、想定リスクを確認し、実装後に内容、テスト結果、残課題を記録する。

1. **完了・アーキテクチャと骨格**: 文書、ディレクトリ、API契約。リスク: 過剰設計、MQL5制約の見落とし
2. **完了・基本EAと戦略**: Controller、設定、シグナルDTO、トレンド戦略。リスク: 未確定足、複数時間足の時刻ずれ
3. **完了・リスク管理**: サイズ計算、DD、日次損失、エクスポージャー。リスク: 再起動、通貨換算、ブローカー仕様
4. **完了・取引管理**: 注文・ポジション管理、`OrderCheck`、約定・スリッページ。リスク: 部分約定、ネッティング・ヘッジ口座の差
5. **完了・MQL5 APIクライアント**: 署名、タイムアウト、厳格なパーサー。リスク: `WebRequest`制約、時刻ずれ
6. **完了・AWS API**: CDK、入力検証、冪等性、Lambdaテスト。リスク: 秘密情報、初期構築、費用
7. **完了・ML推論**: 特徴量、基準モデル、ウォークフォワード、閾値。リスク: データ漏洩、確率校正の劣化
8. **完了・LLMフィルター**: プロバイダーインターフェース、構造化出力、エラー時拒否。リスク: 非決定性、プロバイダー障害
9. **完了・監査データ保存**: DynamoDBイベント、取引テレメトリー、ローカルJSONL。リスク: イベント順序、機密ログ。自動再送キューは後続課題
10. **完了・分析**: パフォーマンス、DD、JSON・CSV・Markdownレポート、Strategy・symbol別集計。リスク: 指標定義の不一致
11. **完了・監視**: EMFメトリクス、SNS通知付きアラーム、保持期間、任意ダッシュボード。リスク: 過剰通知、ログ費用
12. **完了・文書とリリースゲート**: セットアップ、VPS、運用手順、設定表、証跡付き本番チェック。リスク: 文書と実装の乖離

Phase 12で全実装フェーズの開発ゲートは完成したが、実データモデル、LLM回帰評価、AWS実環境、MQL5 VPS、OOS、Walk Forward、デモ、小額実口座を検証するまで取引変更を有効化しない。LLM ALLOW後もRisk Managerが最終権限を持つ。
